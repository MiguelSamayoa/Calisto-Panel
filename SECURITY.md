# Política de seguridad

Calisto Panel es un proyecto personal de host único para una red local, sin TLS ni
exposición a Internet (ver `docs/ARCHITECTURE.md` §8, modelo de amenaza).

## Reportar una vulnerabilidad

Usa **Security → Report a vulnerability** en GitHub (reporte privado). No abras un issue
público ni incluyas tokens, PAT ni rutas reales de tu máquina en el reporte.

Es un proyecto personal: respondo cuando puedo, sin plazos garantizados.
